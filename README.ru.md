Wickle — движок агентов, который EpsilonDelta разрабатывает на Rust. Цель проекта — предоставить встраиваемую в приложения библиотеку, выполняющую цикл принятия решений моделью и вызовов инструментов.

В основе архитектуры — профили агентов (Agent Profiles) для настройки их поведения и адаптеры для подключения различных моделей и инструментов.

**Статус:** В разработке. Агенты поддерживают последовательные вызовы модели и инструментов, отдельные системные входные данные, сохранение результатов, повторное чтение событий, отмену и продолжение после сохранённого ожидания одобрения, ввода или подтверждения внешнего эффекта. Команды продолжения обрабатываются без дублирования; внешние эффекты подтверждает Host. Хуки жизненного цикла поддерживают ограниченное преобразование контекста и аргументов, а также наблюдение за сохранёнными результатами. Экспорты Tool/Hook/ContextSource адаптеров используют зафиксированную конфигурацию и экземпляры для каждого сегмента; ресурсы освобождаются по его завершении. [Среда адаптеров](docs/adapters.md). Общее восстановление прерванного выполнения и проверка результатов-кандидатов пока не поддерживаются. [Запуск агента](docs/agents.md) · [Контракты данных](docs/contracts.md).

[Источники контекста](docs/context-sources.md) с доступом только для чтения поддерживают запросы для Run или шага модели, сохранение данных и проверку текущих прав при повторном использовании.
